# 모아 — 학습자료 캡처

크롬 웹페이지의 지정 영역을 화면 변경 시 캡처하고, 저장 순서대로 PDF를 만드는 Manifest V3 확장 프로그램입니다. 서버·로그인·API 키 없이 실행합니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 프로젝트의 `extension` 폴더를 선택합니다. 1.2.0 ZIP을 받았다면 압축을 푼 폴더 자체를 선택합니다. 선택한 폴더 바로 안에 `manifest.json`이 있어야 합니다.
5. 확장 프로그램 목록에서 **모아**를 고정하면 편리합니다.

Chrome 116 이상을 대상으로 합니다. 크롬 웹스토어에 게시한 제품은 아니며 로컬 설치 방식입니다.

## 1.2.0 업데이트

- 패널에서 확대경을 켜거나 끌 수 있고, 지정 중 Z키로도 전환합니다. 설정을 기억합니다.
- 캡처 영역을 드래그한 뒤 방향키로 영역 전체를 1 CSS px씩 이동하고 Enter로 확정합니다. 화면 배율에 따라 저장 이미지의 픽셀 수와 CSS px은 다를 수 있습니다.
- 드래그 전에는 방향키로 선택 지점을 이동하고 Enter로 시작점을 잡을 수도 있습니다. 이후 방향키로 끝점을 옮긴 뒤 Enter로 확정합니다.
- 지정 후 버튼은 재지정으로 바뀝니다. 재지정을 누르면 해당 기존 영역/점을 즉시 지웁니다. Esc 취소 시에도 복원하지 않습니다.

## 1.1.0 업데이트

- 캡처 영역 선택 시 커서 위에 8배 픽셀 확대경과 원본 이미지 픽셀 좌표를 표시합니다. 확대경은 지정 시작 시점의 화면을 사용합니다. 화면 위쪽에서는 확대경이 아래로 이동합니다.
- 지정한 캡처 테두리와 자동 클릭 십자 표시가 웹페이지에 계속 남습니다. 실제 스크린샷을 찍는 순간에만 숨겨 PDF에 섞이지 않게 합니다.
- 자동 클릭은 드래그가 아닌 한 번 클릭으로 위치를 지정합니다. 지정 클릭은 실제 버튼을 실행하지 않습니다.
- (1.1.0 동작, 1.2.0에서 변경) Esc로 재지정을 취소하면 기존 설정과 표시를 유지합니다. 새 학습자료를 만들면 표시를 초기화합니다.
- 설치용 ZIP 최상위에 manifest.json을 배치했습니다.

업데이트 후 `chrome://extensions`에서 모아를 새로고침하고, 대상 웹페이지도 새로고침한 뒤 확장 아이콘을 눌러주세요.

## 1.0.1 업데이트

탭 URL이 권한 때문에 생략된 경우를 지원하지 않는 페이지로 잘못 판정하던 오류를 수정했습니다. 확장 아이콘 클릭 이벤트에서 패널을 직접 열도록 변경했습니다.

기존 설치 폴더를 수정본으로 교체한 뒤 `chrome://extensions`에서 모아의 새로고침 버튼을 누르세요. 열린 모아 패널을 닫고, 자료가 있는 탭에서 퍼즐 아이콘 → 모아를 직접 눌러 다시 여세요. 확장 프로그램을 삭제할 필요는 없습니다.

## 사용 순서

1. 자료가 있는 일반 웹페이지에서 **모아 확장 아이콘**을 눌러 사이드 패널을 엽니다. 아이콘 클릭으로 해당 탭의 캡처 권한을 부여합니다.
2. **학습자료 만들기**를 누르고 자료 이름을 입력합니다. 기존 캡처가 있으면 삭제 전 확인합니다.
3. **캡처 구역 → 영역 지정**을 눌러 웹페이지 위에서 드래그합니다. 방향키로 1px씩 이동한 뒤 Enter로 확정합니다. 선택을 취소하려면 Esc를 누릅니다.
4. **마우스 좌클릭 위치 → 위치 지정**을 누르고 다음 페이지 버튼의 원하는 지점을 한 번 클릭합니다.
5. **자동 클릭 사용**, 클릭 간격, 변경 감도를 설정합니다. 자동 클릭 없이 수동으로 화면을 넘겨도 캡처됩니다.
6. **캡처 시작**을 누릅니다. 첫 화면을 저장한 뒤, 변경된 화면이 약 0.6초 이상 안정되면 저장합니다.
7. **중지**를 누르고 불필요한 페이지를 삭제한 다음 **PDF 저장**을 누릅니다. A4 한 페이지에 캡처 한 장을 비율을 유지해 배치하며 가로·세로 방향은 이미지에 맞춥니다.

## 동작과 제한

- 표시 중인 웹페이지의 뷰포트 좌표를 사용합니다. 바탕화면·다른 프로그램·브라우저 툴바는 대상이 아닙니다.
- 약 650ms 간격으로 비교합니다. Chrome의 초당 최대 2회 캡처 제한 아래에서 동작하도록 구성했습니다. 아주 빠르게 지나가는 화면은 누락될 수 있습니다.
- 자동 클릭은 첫 캡처 이후 시작하며 **클릭 → 변경 감지 → 안정된 화면 저장 → 다음 클릭** 순서입니다. 설정한 간격은 최소 간격이며, 로딩·저장 시간에 따라 늘어납니다.
- 클릭 후 15초 또는 클릭 간격의 3배 중 큰 시간 동안 유의미한 변경이 없으면 중지합니다. 마지막 페이지에서 무한 클릭하지 않습니다.
- 바로 직전에 저장한 화면과 비교합니다. A → B → A처럼 되돌아가면 A를 다시 저장합니다. 중지 후 다시 시작할 때도 첫 화면을 다시 저장합니다.
- 변경 감도는 비교용 축소 이미지의 변경된 픽셀 비율입니다. 텍스트만 조금 바뀌어 누락되면 **민감 · 1%**로 바꾸거나 캡처 영역을 좁히세요. 동영상·지속적인 애니메이션은 화면이 안정되지 않아 저장되지 않을 수 있습니다.
- 탭 이동, 새로고침, 페이지 이동, 화면 크기·배율 변경 시 중지합니다. 크기나 페이지가 바뀌면 영역을 다시 지정하세요. 사이트 내 스크롤은 화면 좌표를 유지하므로 자동 클릭 위치가 다른 버튼을 가리키지 않도록 주의하세요.
- 작업 중에는 대상 탭과 사이드 패널을 열어두고 브라우저 창을 최소화하지 마세요. 다른 앱 뒤에서의 동작은 보장하지 않습니다.
- 사이트가 합성 클릭(`isTrusted=false`)을 거부하거나 클릭 지점이 iframe 안이면 자동 클릭을 지원하지 않습니다. 자료를 직접 넘기는 캡처 모드를 사용하거나, 자료 본문을 독립된 탭에서 여세요.
- Chrome 내부 페이지, 새 탭, 웹스토어 등 스크립트 주입이 차단된 페이지와 DRM 보호 영상은 지원하지 않습니다.
- 자료 하나당 최대 300장입니다. 고해상도 캡처는 메모리와 저장 공간을 많이 쓰므로 긴 자료는 나눠 저장하세요.
- 이미지 PDF입니다. OCR·검색 가능한 텍스트 변환·전체 페이지 스크롤 캡처·여러 프로젝트 관리·순서 재배열은 포함하지 않습니다.

## 저장 및 권한

캡처는 로컬 IndexedDB, 자료 이름은 Chrome 로컬 저장소에 보관합니다. 패널을 닫아도 저장된 캡처는 유지되며 새 자료 생성 또는 확장 삭제 시 제거됩니다. 확장 프로그램은 캡처 데이터를 외부 서버로 전송하지 않습니다. PDF 라이브러리도 설치 폴더에 포함됩니다.

`activeTab`: 확장 아이콘을 누른 탭의 캡처와 일시적 접근 권한.
`scripting`: 영역 지정과 페이지 내 자동 클릭.
`sidePanel`: 작업 패널.
`storage`: 자료 이름.

## 개발 및 검증

```sh
npm ci
npm run vendor
npm test
npx playwright install chromium
npm run test:browser
node tests/extension-smoke.mjs
```

- 단위 테스트 8개: 탭 권한·URL 누락·차단 페이지·연결 오류 구분, 첫 안정 화면, 중복 방지, 전환 중 제외, 노이즈·점진적 변화.
- 브라우저 통합 테스트: 실제 테스트 페이지의 영역 드래그, 점 클릭 지정·클릭 관통 방지·재지정 취소 시 기존 설정 삭제·방향키 1px 이동·확대경 전환·스크린샷 중 표시 숨김·실패 후 표시 복원, 자동 클릭, 3장 캡처, PDF 다운로드, IndexedDB 복원, 삭제, 다른 탭 보호. Chrome API는 테스트 대역을 사용하며 실제 Playwright 스크린샷·DOM 클릭·PDF 생성으로 검증합니다.
- 실제 확장 로딩 테스트: 원본 Manifest V3 확장을 Chromium에 로드하고 서비스 워커, 패널, 저장소 초기화를 확인합니다.
- PDF 검증: 테스트 출력이 3페이지 A4인지 확인하고 렌더링으로 한글·비율·페이지 번호를 점검했습니다.
- 사용자 Chrome의 실제 사이드 패널에서 권한 부여부터 캡처까지 이어지는 과정과 개별 사이트 호환성은 수동 확인이 필요합니다.

실제 Chrome 확인 방법: `python3 -m http.server 8765`를 프로젝트 폴더에서 실행하고 `http://localhost:8765/tests/demo.html`을 엽니다. 확장 아이콘을 누른 뒤 본문 영역과 다음 페이지 버튼의 클릭 위치를 지정하면 3장을 모을 수 있습니다. 다른 탭으로 전환하거나 창 크기를 바꾸어 중지도 확인하세요.
