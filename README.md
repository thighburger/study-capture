# 모아 — 웹페이지를 나만의 학습자료로

웹페이지에서 필요한 부분을 모아 PDF로 저장하는 **크롬 확장 프로그램**입니다.
확장 프로그램은 크롬에 작은 기능을 추가하는 도구입니다. 모아를 설치하면 웹페이지 옆에 학습자료를 만드는 패널이 열립니다.

**[⬇ 최신 버전 다운로드](https://github.com/thighburger/study-capture/releases/latest/download/study-capture-extension.zip)** · [버전별 변경 내용](https://github.com/thighburger/study-capture/releases)

> 별도 회원가입이나 결제가 필요하지 않습니다. 다운로드에도 GitHub 로그인이 필요하지 않습니다.
> 현재는 크롬 웹스토어가 아닌, 파일을 내려받아 직접 설치하는 방식입니다.

## 시작하기 전에

- **PC용 Google Chrome**이 필요합니다. Windows와 macOS에서 설치할 수 있으며, 모바일 크롬은 대상이 아닙니다.
- Chrome 116 이상을 대상으로 합니다. 동작 확인은 macOS의 Chromium 테스트 환경에서 진행했으며, 사용하는 사이트에 따라 자동 클릭 지원 여부가 다를 수 있습니다.
- 코딩, 터미널 명령어, 별도 프로그램 설치는 필요하지 않습니다.
- 캡처 대상은 **크롬 안에 보이는 웹페이지**입니다. 바탕화면이나 다른 프로그램은 캡처하지 않습니다.

## 1. 파일 다운로드하기

1. 위의 **최신 버전 다운로드**를 누릅니다.
2. `study-capture-extension.zip` 파일이 다운로드됩니다. 보통 컴퓨터의 **다운로드** 폴더에 들어갑니다.
3. ZIP 파일은 여러 파일을 하나로 묶은 압축 파일입니다. **압축을 풀어야 설치할 수 있습니다.**

릴리스 페이지에서 직접 받는 경우 **Assets** 목록의 `study-capture-extension.zip`을 선택하세요. `Source code (zip)`은 개발용 소스 코드이므로 설치 안내와 폴더 구조가 다릅니다.

## 2. 압축을 풀고 보관할 폴더 정하기

### Windows

1. 다운로드한 ZIP 파일을 마우스 오른쪽 버튼으로 클릭합니다.
2. **모두 압축 풀기**를 누르고 안내에 따라 압축을 풉니다.
3. 만들어진 폴더를 문서 등 계속 보관할 위치로 옮깁니다. 예: `문서 → 모아`.

### macOS

1. 다운로드한 ZIP 파일을 더블 클릭합니다.
2. 같은 위치에 압축이 풀린 폴더가 생깁니다.
3. 그 폴더를 문서 등 계속 보관할 위치로 옮깁니다. 예: `문서 → 모아`.

**폴더를 열었을 때 `manifest.json` 파일이 바로 보여야 합니다.** 파일을 직접 열거나 수정할 필요는 없습니다.

```text
모아 ← 나중에 크롬에서 선택할 폴더
├── manifest.json
├── panel.html
├── content.js
├── vendor
└── 그 밖의 파일들
```

> 설치 후에도 이 폴더를 지우거나 다른 곳으로 옮기지 마세요. 크롬이 이 폴더의 파일을 읽어서 실행합니다. ZIP 파일 자체는 설치 후 지워도 됩니다.

## 3. 크롬에 설치하기

1. **Google Chrome**을 실행합니다.
2. 맨 위 주소창에 아래 주소를 입력하고 Enter를 누릅니다. 구글 검색창이 아니라, 인터넷 주소가 표시되는 주소창입니다.

   ```text
   chrome://extensions
   ```

3. 열린 화면 오른쪽 위의 **개발자 모드** 스위치를 켭니다.
   - 직접 다운로드한 확장 프로그램을 설치하기 위한 설정입니다. 코딩을 해야 한다는 뜻은 아닙니다.
4. 왼쪽 위에 나타나는 **압축해제된 확장 프로그램을 로드합니다** 버튼을 누릅니다. 크롬 언어·버전에 따라 문구가 조금 다를 수 있습니다.
5. 2단계에서 준비한 **`manifest.json`이 바로 들어 있는 폴더**를 선택합니다.
   - ZIP 파일이나 `manifest.json` 파일 하나를 선택하는 것이 아닙니다.
6. 목록에 **모아 — 학습자료 캡처** 카드가 나타나고, 카드의 사용 스위치가 켜져 있으면 설치 완료입니다.

회사·학교에서 관리하는 PC는 개발자 모드나 직접 설치가 차단되어 있을 수 있습니다. 해당 경우에는 관리자에게 설치 가능 여부를 확인하세요.

## 4. 모아 아이콘 고정하기

1. 크롬 오른쪽 위의 **퍼즐 모양 아이콘(확장 프로그램)**을 누릅니다.
2. 목록에서 **모아 — 학습자료 캡처**를 찾습니다.
3. 옆의 **핀 모양 아이콘**을 눌러 고정합니다.

이제 주소창 옆에서 모아 아이콘을 바로 누를 수 있습니다. 고정하지 않았어도 퍼즐 메뉴에서 모아를 누르면 열립니다.

## 5. 처음 열고 기본 설정하기

### 자료 페이지에서 열기

1. 학습자료로 만들고 싶은 **일반 웹페이지**를 엽니다.
2. 그 탭에서 **모아 확장 아이콘을 직접 누릅니다.** 오른쪽에 작업 패널이 나타납니다.
3. 패널의 **학습자료 만들기**를 누르고 자료 이름을 입력합니다.

> 모아 아이콘을 누르는 동작으로 현재 탭에 접근할 권한을 줍니다. 다른 사이트로 이동했다면 그 탭에서 아이콘을 다시 눌러주세요. Chrome 설정 화면, 새 탭, 웹스토어에서는 영역을 지정할 수 없습니다.
>
> 이미 모아둔 캡처가 있을 때 새 학습자료를 만들면 기존 캡처가 지워집니다. 필요한 자료는 먼저 PDF로 저장하세요.

### 캡처할 영역 지정하기

1. **캡처 구역 → 영역 지정**을 누릅니다.
2. 웹페이지에서 저장할 부분을 마우스로 드래그합니다.
3. 필요한 경우 **방향키**로 영역 전체를 **1px씩 이동**합니다.
4. **Enter**를 눌러 확정합니다. 청록색 테두리가 남으면 지정된 상태입니다.

- 확대경은 패널의 **영역 지정 시 확대경 사용**에서 켜거나 끌 수 있습니다. 지정 중에는 **Z키**로 전환합니다.
- 취소는 **Esc**입니다.
- 확정 후 버튼은 **재지정**으로 바뀝니다. 재지정을 누르면 이전 영역을 지우고 새로 지정합니다. 취소해도 이전 영역은 복원되지 않습니다.
- 확대경은 지정을 시작한 시점의 화면을 보여줍니다. 방향키의 1px은 웹페이지 좌표 기준이며, 화면 배율에 따라 저장 이미지 픽셀과 다를 수 있습니다.

### 자동 클릭 위치 지정하기 — 필요한 경우만

다음 페이지 버튼을 자동으로 누르고 싶을 때 설정합니다. 직접 페이지를 넘길 예정이라면 **자동 클릭 사용**을 꺼두고 이 단계는 건너뛰세요.

1. **마우스 좌클릭 위치 → 위치 지정**을 누릅니다.
2. 웹페이지의 **다음 페이지 버튼 위를 한 번 클릭**합니다. 드래그하지 않아도 됩니다.
3. 주황색 십자 표시가 남으면 지정 완료입니다. 이때의 클릭은 위치 지정용이며 실제로 페이지를 넘기지 않습니다.
4. **자동 클릭 사용**이 켜져 있는지 확인합니다.

### 처음에는 이 설정으로 시작하세요

| 설정 | 시작값 | 의미 |
|---|---|---|
| 클릭 간격 | **2초에 한 번** | 자동으로 다음 버튼을 누르는 최소 간격입니다. 로딩·캡처에 시간이 걸리면 더 길어집니다. |
| 변경 감지 | **보통 · 3%** | 선택 영역에서 화면이 어느 정도 바뀌었을 때 새 장면으로 판단할지 정합니다. |
| 확대경 | 취향에 따라 켜기 | 경계를 자세히 보고 지정할 때 사용합니다. |

텍스트가 조금만 바뀌어 캡처가 누락되면 **민감 · 1%**로 바꿔보세요. 계속 움직이는 영상이나 애니메이션은 화면이 안정되지 않아 저장되지 않을 수 있습니다.

**여기까지가 설치와 초기 설정입니다.** 실제 캡처 진행과 PDF 저장 시연 영상은 추후 추가할 예정입니다.

## 알아두면 좋은 점

- 작업 중에는 **대상 탭과 모아 패널을 열어두세요.** 탭 이동·새로고침·화면 크기나 배율 변경 시 캡처가 중지됩니다. 크기를 바꾸었다면 영역을 다시 지정하세요.
- 테두리와 십자 표시는 캡처 순간에 숨기므로 저장 이미지에 포함되지 않습니다.
- 일부 사이트는 자동 클릭을 받지 않습니다. 다른 페이지를 안에 넣어 보여주는 화면(iframe) 내부의 자동 클릭도 지원하지 않습니다. 이 경우 자동 클릭을 끄고 직접 넘기는 방식을 사용하세요.
- 한 자료에 최대 **300장**을 모을 수 있습니다. 저장된 PDF는 이미지 기반이므로 글자 검색이나 복사는 지원하지 않습니다.
- 캡처는 이 PC의 확장 프로그램 저장소에 보관되며, 모아는 캡처를 외부 서버로 전송하지 않습니다. 패널을 닫아도 저장된 캡처는 남습니다.

## 새 버전으로 업데이트하기

직접 설치한 버전은 자동 업데이트되지 않습니다. 이 README 위의 **최신 버전 다운로드** 링크는 새 릴리스가 올라오면 해당 버전을 내려받습니다.

1. 진행 중인 캡처를 중지하고 필요한 자료를 PDF로 저장합니다.
2. 최신 ZIP을 받아 압축을 풉니다.
3. 새 폴더 **안의 파일과 `vendor` 폴더를 모두** 기존 설치 폴더에 복사해 덮어씁니다. 기존 설치 폴더의 경로는 유지합니다.
4. `chrome://extensions`에서 **모아 카드의 새로고침 아이콘(둥근 화살표)**을 누릅니다.
5. 자료가 열린 웹페이지도 새로고침합니다.
6. 모아 아이콘을 다시 눌러 캡처 영역과 클릭 위치를 지정합니다.

확장 프로그램을 삭제하고 다시 설치할 필요는 없습니다. **제거** 버튼을 누르면 보관된 캡처도 지워질 수 있습니다.

## 설치가 안 될 때

| 보이는 상황 | 확인할 내용 |
|---|---|
| **매니페스트 파일이 없거나 읽을 수 없습니다** | 선택한 폴더 바로 안에 `manifest.json`이 있는지 확인하세요. 한 단계 바깥 폴더나 ZIP 파일을 선택하면 안 됩니다. |
| **압축해제된 확장 프로그램 로드 버튼이 안 보임** | `chrome://extensions` 오른쪽 위에서 개발자 모드를 켜세요. |
| **접근 권한이 없습니다** | 자료가 열린 탭에서 퍼즐 아이콘 → 모아를 직접 누른 뒤 다시 시도하세요. 패널 안 버튼만 누르는 것으로는 권한이 부여되지 않습니다. |
| **드래그했는데 지정이 끝나지 않음** | 웹페이지에 마우스를 둔 상태에서 Enter로 확정하세요. |
| **설정 화면에서 영역 지정이 안 됨** | Chrome 설정·새 탭·웹스토어를 벗어나 일반 웹페이지에서 실행하세요. |
| **업데이트했는데 예전 화면이 나옴** | 확장 프로그램과 자료 웹페이지를 모두 새로고침했는지 확인하세요. |
| **자동 클릭 후 중지됨** | 마지막 페이지인지, 실제 클릭 가능한 버튼인지 확인하세요. 변경을 충분히 감지하지 못한 경우 감도를 높여보세요. |

해결되지 않으면 [문제 제보](https://github.com/thighburger/study-capture/issues)에 크롬 버전, 운영체제, 오류 문구와 재현 순서를 남겨주세요. 비밀번호나 개인 자료가 보이는 화면은 올리지 마세요.
